## v1.0.0

### 更新说明

新增 OpenViking 接入 DeepAgents 的上下文管理能力，支持消息增量写入、工具结果压缩与回读、输入预算、提交归档、记忆召回及 checkpoint 恢复。具体请参见《[OpenViking 接入 DeepAgents 实现上下文管理](./deepagents_context_management.md)》。
