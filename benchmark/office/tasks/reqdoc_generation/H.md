【H组执行方法指导】
1. 按当前章节需要读取资料，保留本轮解析结果供后续定位。Markdown、JSON 直接读取；DOCX 使用 python-docx 读取段落和表格；PDF 统一使用环境已安装的 pypdf：通过 PdfReader 逐页调用 extract_text()，保留页码并将解析结果保存到 tmp/ 复用；不运行 pip 安装或反复探测其他 PDF 解析器；Excel 使用 openpyxl 读取工作表状态、表头和数据。工作簿明细留在脚本及 JSON 中，向模型输出口径、字段、处理计数和必要样例。

2. 使用辅助文件中的函数保留原始记录及处理事件。read_records 返回 raw（全部原字段）和 source_row（原行号）；筛选与排除信息另行记录。结果 JSON 保留这些完整记录，使每个结果能追溯到实际来源。函数适用于本轮台账和事件表：首行为完整唯一表头，事件时间为 ISO 8601 字符串或 datetime，且与 period_end 的时区可以比较；调用前按本轮资料确认列名和口径。

3. RD05、RD06 的脚本各自导入辅助文件，独立读取原工作簿并计算。统计区间和有效意图条件从本轮 MET-00 取得；事件调用 effective_events，再按有效意图和本章 phase 取记录。首次与重试按 retry_of 区分，非终态按本轮口径处理。每章完成时核对原字段齐全、原值与行号对应、筛选和排除覆盖，以及分子分母的集合关系；独立复算后记录核对结果，再保存正文并进入下一章。

辅助函数的使用方式：

在 RD05、RD06 的独立脚本中导入同一文件：

```python
import sys
from pathlib import Path

sys.path.insert(0, str(Path("inputs").resolve()))
from record_helpers import read_records, effective_events
```

- `read_records("inputs/metrics.xlsx", sheet_name)` 返回每行的 `raw`（全部原字段）与 `source_row`（实际 Excel 行号），适用于意图台账和事件导出表；`sheet_name` 以本轮工作簿为准。
- 读取事件表后，调用 `effective_events(records, period_end)`，其中 `period_end` 从本轮 MET-00 解析，并与事件时间采用一致时区。函数先按期末截断，再按 `event_id` 去重，最后按 `(intent_id, phase, attempt_id)` 保留最大 `seq`；同时返回逐条被排除的完整记录及原因。
- 有效意图筛选与本章 `phase` 选择由各章脚本完成；函数不代替有效意图、首次／重试、非终态及指标分子分母的业务判定。有效与排除结果均沿用完整 `raw` 和 `source_row`，逐条补充本章判定原因。
- 校验记录覆盖时，以 `(工作表名, source_row)` 对照原表和输出证据，检查有效与排除记录的并集覆盖来源，且原字段、原值一致；不要仅用记录总数判断覆盖。
